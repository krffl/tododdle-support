# React Native example

`App.tsx` shows the report sheet in a React Native or Expo app. Copy it into an app that has
`@krffl/tododdle-support-react-native` installed. The example also uses
`@react-native-async-storage/async-storage` (to keep the config offline) and `expo-image-picker`
(so the person can choose a screenshot); both are the app's choice and optional.
